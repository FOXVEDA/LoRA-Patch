# LoRA-Patch

**LoRA-Patch: Defending Against Backdoored LoRA Adapters via Directional Steering**

Accepted to **EMNLP 2026 — Main Conference**.

## Code release status

The implementation and accompanying materials are being prepared for public release. This repository will host the official implementation of LoRA-Patch.

We plan to provide the source code, usage examples, configuration files, and instructions for obtaining the required models and datasets and setting up the environment.

Release preparation has been delayed due to the first author's ongoing job search. Updates will be posted here as the release materials become available. Thank you for your patience and interest in our work.

## About

LoRA-Patch is a runtime defense against backdoored LoRA adapters. It uses directional steering without retraining or modifying the underlying model or adapter weights.
